# ТЗ v1: Доступ по номеру телефона + белая тема (05.11.2026)

Контекст: TimeControl, Telegram Mini App (FastAPI + vanilla JS `webapp/`).
Роли: работник и руководитель (бригадира нет). SPEC: §12–14, §22, §28.

## Задача 1. Поток «незнакомец → заявка → одобрение руководителем»

Сейчас: незнакомец пишет боту → бот просит телефон → если телефон есть в
`users` (заведён заранее, `tg_id IS NULL`) → мгновенная привязка. Если телефона
нет — тупик: «Ваш номер не найден в системе».

Проблема: руководитель не может заранее знать телефоны всех сезонных рабочих.
Нужен поток: человек сам делится номером, руководитель видит заявку и одобряет.

### Требования

**Бот (`app/bot/router.py`):**
1. Незнакомец делится контактом (уже реализовано, `request_contact`).
2. Если телефон НЕ найден среди `users` (`tg_id IS NULL`):
   - создать заявку: новая таблица `access_requests`
     (`id, tg_id, name, phone, lang, status[pending/approved/rejected],
     created_at, decided_at, decided_by`) — миграция через `app/create_tables.py`
     или `Base.metadata.create_all` (проект без alembic, см. `app/db.py`);
   - ответить человеку: «Заявка отправлена руководителю. После одобрения вы
     получите доступ» (ключ `request_sent`);
   - уведомить ВСЕХ активных руководителей (`is_manager=1, is_active=1`)
     сообщением: имя, телефон, username (если есть) + inline-кнопки
     «✅ Одобрить» / «❌ Отклонить» (`callback_data`: `acc:approve:<id>` /
     `acc:reject:<id>`).
3. Повторный контакт того же человека: если заявка `pending` — ответить
   «Заявка уже на рассмотрении» (`request_pending`), не создавать дубль.
4. Callback-кнопки обрабатывать в том же webhook (`update.get("callback_query")`,
   сейчас игнорируется — добавить). Одобрение:
   - создать `User` (name из заявки или из Telegram, phone, lang, `is_active=1`,
     `is_manager=0`, `tg_id` из заявки);
   - заявке `status=approved, decided_at, decided_by`;
   - ответить callback (`answerCallbackQuery`) «Одобрено»;
   - написать человеку: «Вам выдан доступ. Откройте мини-апп / напишите
     количество часов» (`approved_ok`);
   - дублировать руководителю подтверждение.
   Отклонение: `status=rejected`, человеку «Заявка отклонена» (`rejected_info`).
5. Одобрять может только руководитель (проверка `is_manager` по `from.id`).
6. Кнопку «Напомнить» НЕ делать (вне рамок).

**Мини-апп (`webapp/app.js`, `app/routers/miniapp.py`):**
7. При 401 от `/api/me` показывать на `screenLogin` не «Проверка данных...»,
   а понятное сообщение по коду ответа:
   - `not_registered` → «Вы ещё не в системе. Откройте бота, отправьте номер —
     после одобрения руководителем появится доступ» + кнопка «Открыть бота»
     (ссылка из `BOT_USERNAME` env, дефолт `@agrofirmbot`).
   - `deactivated` → «Доступ отключён. Обратитесь к руководителю».
   Для этого `/api/me` при 401 должен возвращать `{"detail": "...", "code":
   "not_registered" | "deactivated"}` — различить два случая (сейчас оба
   дают одинаковую строку).

**i18n (`app/i18n/{ru,uk,es}.json`):** новые ключи: `request_sent`,
`request_pending`, `approved_ok`, `rejected_info`, `mgr_new_request`,
`mgr_approved_confirm`, `mgr_rejected_confirm`, `approve_btn`, `reject_btn`,
`webapp_not_registered`, `webapp_deactivated`, `open_bot_btn`. Все 3 языка.

**Не забыть:** `allowed_updates` в `setup_webhook()` добавить `callback_query`
(сейчас только `["message"]` — кнопки не дойдут!).

## Задача 2. Белая тема

Сейчас: жёсткая тёмная палитра в `webapp/styles.css` `:root` (`--bg:#0E1412` и
др.) + `<meta name="theme-color" content="#0E1412">`.

Требования:
1. Переключить палитру на светлую: фон белый/почти белый, тёмный текст,
   поверхности светло-серые, акцент зелёный оставить (`#16A34A` вместо
   `#4ADE80` для контраста на белом, `--accent-ink` белый).
2. Все полупрозрачные оверлеи (`rgba(0,0,0,.45)` у sheet-backdrop) проверить
   на светлой теме.
3. `theme-color` в `index.html` → белый (`#FFFFFF`).
4. Скелетоны/бейджи/тосты — проверить контраст на белом.
5. Тёмную тему НЕ сохранять (не делать переключатель) — просто светлая,
   по решению владельца.
6. Поднять версии: `styles.css?v=12`, `app.js?v=12` в `index.html`.
