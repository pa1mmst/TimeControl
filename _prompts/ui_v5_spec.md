# UI v5 — ТЗ на перестройку Mini App
*05.11.2026. Источник решений: пользователь (05.11), references.md (подтверждённые паттерны), mockup-v5.html (визуальный эталон).*

## 0. Стратегические решения (фиксированы, не обсуждать)
1. **Ролей две: работник и руководитель.** Роль «бригадир/учётчик» в UI НЕ существует. Работник вводит только свои часы. Ввод/исправление за других — только у руководителя (через матрицу задания).
2. **Работник: ОДИН экран, без вкладок.** Задание на сегодня → большая кнопка «Записать часы» → карточка «К выплате» → история. (references.md п.1: Jibble, Connecteam.)
3. **Руководитель: 3 вкладки** — Сегодня · Задания · Деньги. Люди, заказчики, инвентарь, язык — из шапки ☰. (references.md п.2: Homebase «Needs Review».)
4. **Проблемы наверху:** блок «Требует внимания» на «Сегодня» руководителя. Пустой блок = «Всё в порядке ✓» (это хорошо, не пугать).
5. **Записать часы = 2 тапа:** кнопка → 6/8/10/… → Сохранить.
6. **Таблица люди × дни — только внутри задания.**
7. Бэкенд НЕ трогать: все данные уже есть в эндпоинтах (см. §3).

## 3. Точные требования

### 3.1 Работник — один экран (screenToday)
Порядок сверху вниз:
1. Шапка: имя + дата. Кнопка ☰ (меню работника, §3.3).
2. Баннер «За вчера часы не записаны → Записать» — только если это видно из имеющихся данных (/api/me/today, /api/me/history). Если данных нет — не показывать, бэкенд не расширять.
3. Карточка задания на сегодня: локация · клиент, люди (chips), большая кнопка «Записать часы». После ввода: зелёная плашка «✓ Записано N ч · изменить» (повторный тап открывает sheet с причиной исправления — как сейчас в API).
4. Карточка «К выплате за {месяц}»: сумма крупно, «начислено X · аванс Y» (из /api/me/money). Тап → screenMoney (детально).
5. «История»: последние ~5 записей из /api/me/history (день · локация · часы; пометка «исправлено» как сейчас). Ссылка «Вся история ›» → screenHistory.
Нижних вкладок у работника НЕТ.

### 3.2 Руководитель
Вкладки (внизу): Сегодня · Задания · Деньги. В шапке ☰ (§3.3).

**Сегодня (screenManagerDash):**
1. 3 плитки-статистики: на работе / часов / без часов (из /api/dashboard/today; «без часов» красным, если > 0).
2. «Требует внимания»: кто без часов (кнопка «Напомнить» — заглушка-тост «Отправлено» НЕ нужна: если реального API нет, кнопка открывает задание/карточку человека; ничего не выдумывать), задания, где 0 записей. Пусто → «Всё в порядке ✓».
3. Активные задания: карточки с chips по людям (зелёный «Имя 8», красный «Имя —»). Тап → screenMatrix.
4. FAB «+ Задание» → screenNewTask.

**Задания (screenTasks):** сегменты Активные | Завершённые; карточки (название, дата, чел., часов); тап → screenMatrix.

**Деньги (screenMoney):** «К выплате всего» + «начислено · авансы»; список сотрудников (имя · часы · сумма); строки «+ Аванс» и «Отчёты»; кнопка «Закрыть период». Сегмент «Отчёты» — screenReports.

### 3.3 Меню ☰ (sheet снизу, как в макете)
- Работник: Вся история › · Мне причитается › · Мой инвентарь › (items, где holder = я; если у list_items нет фильтра по держателю-себе — проверить app/routers/inventory.py, _check_holder там есть) · Язык (ru/uk/es, как сейчас).
- Руководитель: Люди › (screenTeam: сегменты Люди · Инвентарь) · Заказчики и локации › (screenClients) · Язык.

### 3.4 Ввод часов (sheet вместо screenHoursEntry)
- Заголовок «Сколько часов сегодня?» / при исправлении «Исправить часы».
- Кнопки 6 / 8 / 10 / … (… — своя цифра). Выбор подсвечен.
- У руководителя при исправлении чужой ячейки — поле «Причина» (обязательна, как требует API).
- «Сохранить» — один тап. Успех → sheet закрыт, экран обновлён, тост «Записано».
- API: существующие /api/work-entries (свой ввод) и групповой/исправление — как реализовано сейчас (см. app.js, app/routers/work_entries.py). Ничего не выдумывать.

### 3.5 Навигация и роли
- `renderNav()`: работник — без вкладок; руководитель — 3 вкладки.
- `init()`: работник → screenToday; руководитель → screenManagerDash.
- Все переходы — через существующий showScreen. Мёртвых ссылок на удалённые экраны не оставить.
- Кэш-бастинг: в index.html поднять версию `app.js?v=8` → `?v=9` (и styles.css, если менялся).
