# Похожие приложения — что взять в TimeControl
*30.10.2026. Источник: знания агента + проверка справок Homebase и Connecteam (30.10.2026). Скриншоты не собраны: веб-поиск был недоступен (блокировка DuckDuckGo). Перед реализацией стоит посмотреть живые приложения на телефоне.*

## Подтверждено по справкам
- **Homebase:** табели, требующие внимания руководителя, собраны в разделе **Needs Review** вверху страницы: «No Show» (не вышел на смену), «Missing Clock Out» (не отметил уход). → Сначала проблемы, потом всё остальное.
- **Connecteam:** у руководителя есть вкладка **Today** (кто когда отметился, где). Среди минусов обзорщики называют: **для учёта времени нужен интернет**. → Работа без связи даст нам преимущество для полей.

## По знаниям (проверить на живых приложениях)
| Приложение | Что у них хорошо | Берём |
|---|---|---|
| Connecteam | У работника главная = одна большая кнопка + задание на сегодня | Одна главная кнопка «Записать часы» |
| Homebase / Deputy | У руководителя сначала исключения, подтверждение табелей | Блок «Требует внимания» первым на экране |
| Jibble / Clockify | Под кнопкой сразу лента по дням | История — продолжение главного экрана, не отдельная вкладка |
| PickTrace / Harvust (агро) | Бригадир отмечает всю бригаду списком с галочками, работает офлайн | «За бригаду» = список с галочками, все отмечены по умолчанию |
| Telegram-боты учёта | Вопрос «сколько часов?» с кнопками 8/10/другое | Вечернее напоминание в боте с кнопками |

## Выводы для макета v5
1. **Работник: один экран.** Задание → кнопка → лента дней → карточка «к выплате». Без вкладок.
2. **Руководитель: 3 вкладки.** Сегодня (проблемы + задания) · Задания · Деньги. Люди / заказчики / инвентарь — из шапки (☰).
3. **Записать часы = 2 тапа:** кнопка → выбрать 8/10/другое → готово (Telegram MainButton).
4. **Пустое = хорошо:** нет проблем — «Всё в порядке ✓», а не пустая таблица.
5. **Таблица люди × дни** — только внутри экрана задания, не на главной.
6. **Цвета темы Telegram** (светлая/тёмная автоматически) вместо своей тёмно-зелёной.
